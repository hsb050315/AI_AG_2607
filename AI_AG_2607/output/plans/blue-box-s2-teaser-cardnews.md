- Subject: Blue Box (アオのハコ) Season 2 teaser promotion — real Netflix anime, do not fabricate plot facts
- Deliverable: 6 sections. Section 1 = thumbnail. Sections 2–6 = a 기승전결 (setup / development / turn / resolution) arc
- Design concept (source of truth = Phase-1 design-concept doc "푸른 상자 2기 티저"):
  - Theme: "a youth gymnasium sunk blue like underwater"
  - Dominant #1C3F73 (deep blue) + Secondary #4FA3C7 (aqua)
  - Accent #FF7A5C (dawn coral) — "a single strand of early-morning light", ~10% usage only
  - Mood: plain, restrained negative space; the stillness of winter; slow-burn romance + sports
  - Type/layout: bold sans-serif headline + plain body, teaser / card-news layout
- Reference roles:
  - `cn_01` (한국저작권위원회 AI 저작권 card news): frame-to-frame rhythm (hook → explain → conclude → contrast/split → typographic frame → CTA), keyword highlight boxes, one repeated per-frame motif

## Global rules

- Canvas 1080×1080 (square), safe margin 96px all sides
- Palette: background #1C3F73; aqua #4FA3C7 for sub-elements, lines, tags; coral #FF7A5C only one hit per frame (a word, an underline, a dot), never above ~10% area — if a frame needs two, one becomes aqua
- Text: near-white #F2F6FA body on deep blue; headline weight ExtraBold/Black, body Regular
- Every frame: small "青のbox / BLUE BOX" wordmark top-left, frame number "02 / 06" top-right in aqua
- One idea per frame. Wide top negative space. Headline line ≤ ~25 Korean characters
- Water motif: a thin horizontal "surface line" that sits lower each frame (2→6) as if the viewer is sinking, then returns to the top in frame 6 — the visual through-line of the arc
- Every factual claim (broadcast timing, platform, episode count, staff, cast, quotes) is a PLACEHOLDER and must be replaced with confirmed official information before publishing; if S2 details are not yet public, sections 5–6 wait
