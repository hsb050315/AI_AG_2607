여름 카드뉴스(3프레임) 디자인 레퍼런스
(수집일: 2026-08-26 | 3·4번 재선정: 2026-08-26 | 입력: design-concept 문서 https://docs.google.com/document/d/1PIyZkqtnNJOQXqJ3Gs1omCQd8EfqtYFHl6hDiBETPR4/edit)

컨셉 요약(design-concept 문서 기준)
- 무드 키워드: 청량한 해방감 / 절제된 휴식 / 리퀴드 청량 / 아날로그 온기
- 컨셉 스테이트먼트: "시원한 물빛 위에 선셋 오렌지 한 스푼 — 눈이 쉬어가는 여백 속에서 휴가의 설렘을 건네는 청량 카드뉴스."
- 컬러: 오션 아쿠아 블루 #1F86AD(주조) / 소프트 민트 #9FDCD2 / 웜 샌드 #EFE2CC / 선셋 코럴 #FF6B4A(강조) / 클라우드 화이트 #F7FBFC(배경) / 딥 오션 네이비 #12384A(텍스트) — 비율 50/30/10/10
- 타이포: 제목 = 둥근 산세리프 볼드(Gmarket Sans + Poppins Bold) / 본문 = 라이트(Pretendard + Inter), 넓은 여백
- 대상: 인스타그램 카드뉴스 3프레임, 2030 남녀 전반, 청량·휴가 감성


■ 조사 방법
- 사용 갤러리 / 검색어
  · Pinterest(pinterest.com, kr.pinterest.com) — "summer instagram carousel design", "여름 카드뉴스 디자인"
  · 검색 그리드에서 컨셉(무드·컬러·매체) 일치도가 높은 후보를 추려 최종 5장 선정
- 3·4번 재선정(2026-08-26): 초기 5장 중 3번(tooldi 배송안내)·4번(구름 종이 메모)이 '아날로그 온기' 계열이라 보드 전체의 청량 방향과 겉돌아 사용자가 제외. 같은 검색 그리드에서 후보를 다시 추려 6장을 앱에 띄우고, 사용자가 2장(얼음 큐브 보더 / JOEGUSH 팝업)을 최종 선택 → 3·4번 슬롯에 반영.
- 포함 기준: ① 매체가 인스타그램 카드뉴스/정사각·세로 SNS 그래픽일 것 ② 물빛 블루 주조 + 넓은 여백 + 둥근 볼드 헤드라인 중 최소 2개 충족 ③ 휴가/시즌 인사 또는 휴무·배송 안내처럼 3프레임으로 풀 수 있는 정보 구조
- 제외 기준: 과채도 네온·열대 패턴 남발(절제된 휴식과 상충), 라임·틸 위주로 선셋 코럴 강조가 들어갈 자리가 없는 팔레트, 4분할 이상 고밀도 인포그래픽(여백 부족), 세피아·빈티지 필터(청량과 상충)
- 메타데이터 한계: 스킬 규칙에 따라 로그인·회원가입을 하지 않고 로그아웃 상태로만 브라우징함. 로그아웃 Pinterest는 핀 상세페이지 링크·제작자·설명 텍스트를 노출하지 않으므로 개별 핀의 상세페이지 URL과 제작자는 확인 불가. 레퍼런스는 그리드 썸네일(i.pinimg.com/236x/…)을 원본 크기(i.pinimg.com/736x/…)로 치환해 전체 레이아웃을 캡처하는 방식으로 확보함(Pinterest 썸네일은 크롭이 아니라 전체 구성이므로 736x 이미지가 완성 레이아웃 전체를 담음).

■ 종합 제안
- 레이아웃: 프레임 1(표지) = 1·5번처럼 물빛 사진/컬러 풀블리드 + 둥근 볼드 2줄 헤드라인 + 여백 최대. 프레임 2(본문·안내) = 2번의 날짜 pill + 2줄 본문 구조, 또는 3번처럼 중앙을 비우고 테두리 오브제로만 프레이밍한 저정보 구조로 핵심 정보 1덩어리만. 프레임 3(마무리) = 4번처럼 채도 낮춘 사진 한 장 + 얇은 라이트 타이포 3줄 + 브랜드/장소/날짜 태그.
- 컬러·무드: 5장 공통으로 '물빛 블루가 화면의 주인, 강조는 딱 하나'라는 원칙이 보임 → 오션 아쿠아 블루 #1F86AD 주조 + 클라우드 화이트 여백을 기본판으로 하고, 선셋 코럴 #FF6B4A는 프레임당 1개 요소(칵테일·날짜 하이라이트)에만. 3번은 소프트 민트 #9FDCD2를, 4번은 채도를 낮춘 '차분한 청량'을 담당 → 3프레임에 걸쳐 쨍 → 차분으로 톤을 살짝 눕히는 흐름이 가능. 웜 샌드는 4번 사진의 모래톤 정도로만 은은하게. 재선정으로 '아날로그 온기'(손그림·종이 오브제) 계열은 보드에서 빠졌으므로, 그 무드는 design-concept 문서 팔레트 안에서만 소극적으로 반영하고 이번 보드의 시각 방향은 청량·리퀴드·절제 3축으로 좁힘. 레퍼런스에 자주 등장하는 라임/네온·핫핑크는 채택하지 않음.
- 타이포: 헤드라인은 1·2·5번이 둥근 산세리프 볼드(또는 글로시 볼드) → Gmarket Sans/Poppins Bold 방향 확정적. 3·4번은 얇은 화이트 타이포로 '절제' 축을 담당 → 표지·본문은 볼드, 마무리는 라이트로 대비를 준다. 본문은 4·5번처럼 라이트 웨이트 2~3줄, 자간 넓게. 영문 서브카피("Hello Summer") 병기가 청량·휴가 감성에 잘 맞음.
- 색상 확정은 사용자 최종 컨펌 필요. HEX·비율은 design-concept 문서 팔레트를 우선하며, 위 제안은 그 팔레트를 레퍼런스로 검증한 결과임.
