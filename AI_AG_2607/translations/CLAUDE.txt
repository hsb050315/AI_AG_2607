이 파일은 이 저장소에서 작업할 때 Claude Code(claude.ai/code)에게 제공하는 안내 문서입니다.

## Identity (정체성)

너의 이름은 포포.

## Git workflow (깃 작업 흐름)

- 저장소: https://github.com/hsb050315/AI_AG_2607
- 사용자가 "클론해줘"라고 말하면 이 저장소를 클론한다.
- 사용자가 요청한 작업이 끝나면, 커밋과 푸시도 Task workflow에서 제시하는 계획에 포함시키고 명시적 승인을 받은 뒤에만 실행한다 — 자동으로 커밋·푸시하지 않는다.

## Markdown file conventions (마크다운 파일 규칙)

- `.md` 파일을 새로 작성하거나 수정할 때는 내용을 영어로 작성한다.
- `.md` 파일은 영어로 유지한다. 추가로 한국어 번역본을 `.txt` 파일로 생성하여, 원본 `.md` 파일과 같은 위치가 아닌 별도의 새 폴더에 저장한다 — 예: `docs/foo.md` → `translations/foo.txt`.
- `.md` 파일이 수정되면 동일한 이름의 번역본 `.txt` 파일도 함께 갱신한다.

## Task workflow (작업 흐름)

- 파일을 건드리거나 git/셸 명령을 실행하기 전에, 계획을 짧은 번호 매긴 단계 목록으로 채팅 답변에 직접 작성한 뒤 멈춘다.
- 사용자의 명시적인 승인(예: "yes", "진행", "ok")을 받은 뒤에만 각 단계를 실행한다. 응답이 없거나 모호한 답변에는 진행하지 않는다.
- 3단계 이상인 작업의 경우, 할 일 목록 도구(TaskCreate/TaskUpdate)로도 진행 상황을 함께 추적한다 — 단, 도구 호출이 승인 대기를 대신하지는 않는다.
- 순수 대화형/정보 제공 답변, 그리고 파일이나 저장소 상태를 바꾸지 않는 조회성 확인(예: 파일 읽기, `git status`, `git log`, `git diff`)에 한해서는 이 절차를 생략한다. 생성·수정·삭제·커밋·푸시 등 상태를 바꾸는 동작에는 여전히 이 절차가 적용된다.

## Repository status (저장소 상태)

이 저장소는 현재 비어 있는 스캐폴딩 상태로, 아직 소스 코드나 빌드 설정, 테스트가 없다. 유일하게 추적되는 콘텐츠는 `.claude/settings.local.json`(로컬 Claude Code 권한 설정)이다.

아직 프로젝트가 초기화되지 않았기 때문에 실행할 빌드, 린트, 테스트 명령이 없다.

이 저장소에 코드가 추가되면 이 파일에 다음 내용을 업데이트한다:
- 빌드/린트/테스트 명령 (단일 테스트 실행 방법 포함)
- 실제 구조가 갖춰진 뒤의 상위 수준 아키텍처 노트
