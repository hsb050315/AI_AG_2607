# HANDOFF (한국어 번역)

## 작업 목표
`gws-doc`, `gws-calendar` 두 구글 워크스페이스 스킬에서 한글(비-ASCII) 텍스트가 깨지는 버그를 고치고, 실제로 고쳐졌는지 테스트로 확인해서 두 스킬을 안정적으로 쓸 수 있는 상태로 만드는 것.

## 사용자 제약조건
- 파일 전체를 한 번에 읽지 말고, 필요한 함수나 줄 범위만 나눠서 읽을 것.
- 명령어 실행 결과는 오류와 핵심 내용만 100줄 이내로 확인하고, 긴 출력은 파일로 저장한 뒤 요약만 보고할 것.
- 사용자에게 설명할 때는 어려운 용어 없이 쉽게 설명할 것.
- 프로젝트 규칙(CLAUDE.md): 작은 변경은 승인 기다리지 않고 자동으로 커밋/푸시. `.md` 파일은 영어로 작성하고 별도 폴더에 한글 `.txt` 번역본을 함께 둘 것. 구조를 크게 바꾸거나 여러 부분에 영향을 주는 대규모 작업은 계획을 먼저 보여주고 명시적 승인을 받을 것.

## 변경한 파일
- `.claude/skills/gws-calendar/SKILL.md` — 한글 텍스트 다룰 때 Bash 대신 PowerShell을 쓰라는 안내, 파일로 스크립트를 작성하는 우회 방법 추가.
- `.claude/skills/gws-calendar/scripts/gws_calendar_builder.py` — `_resolve_gws_argv_prefix()`로 cmd.exe가 인자를 재해석해서 깨지는 버그 수정.
- `.claude/skills/gws-doc/SKILL.md` — 위와 동일한 PowerShell 안내 추가.
- `.claude/skills/gws-doc/scripts/gws_docs_builder.py` — 위와 동일한 cmd.exe 버그 수정.
- `.claude/skills/gws-doc/evals/evals.json` — 테스트 시나리오 3개 정의.
- `.claude/skills/gws-doc-workspace/iteration-1/**` — 스킬 사용/미사용 x 시나리오 3개, 총 6번의 테스트 채점 결과, 이를 합산한 `benchmark.json`/`benchmark.md`, 정적 결과 확인용 `review.html`.

## 완료한 내용
- **gws-doc**: 정식 테스트 절차 완료 — 6번 실행 채점, 결과 합산(스킬 사용 시 100% 성공, 미사용 시 41.7% 성공), 분석 메모 3개 기록, 정적 결과 페이지 `review.html` 생성 및 사용자 확인·승인 완료.
- **gws-calendar**: 코드 버그 수정 완료(docs와 동일한 cmd.exe 문제). 이후 간단한 수동 테스트 진행 — 스킬의 `insert_event()`로 한글이 들어간 실제 캘린더 일정을 만들어 깨지지 않는 것을 확인하고, 테스트 일정은 바로 삭제, 삭제 명령이 남긴 빈 `download.html` 파일도 정리.

## 남은 작업
- `gws-calendar`는 `gws-doc-workspace`처럼 정식 테스트(6회 반복 채점·합산) 절차는 없음 — 사용자가 "간단한 테스트만" 요청해서 위의 간단한 확인만 진행함.
- `benchmark.md`는 영어로만 작성되어 있고 한글 `.txt` 번역본이 아직 없음 — 내부 자동 생성 도구 산출물로 보고 번역 대상에서 제외했으나, 사용자에게 명시적으로 확인받지는 않음.
- gws-doc 테스트 과정에서 실제로 만들어진 구글 문서 3개가 사용자 드라이브에 그대로 남아있음 — 아직 정리 요청받지 않아 삭제하지 않음.
- CLAUDE.md의 "작업 시작 전 TaskCreate로 할 일 목록 보여주기" 규칙이 이번 작업 흐름에서는 적용되지 않았음.

## 다음에 실행할 작업
- 사용자가 나중에 `gws-calendar`도 `gws-doc`만큼 꼼꼼하게(정식 테스트·합산·리뷰 절차) 검증하길 원하면, `.claude/skills/gws-calendar/evals/` 아래에 테스트 시나리오를 만들고 채점 → 합산 → 리뷰 과정을 다시 진행.
- gws-doc 테스트 중 만들어진 구글 문서 3개를 정리(삭제)할지 사용자에게 확인.
- `benchmark.md`에 한글 `.txt` 번역이 필요한지, 아니면 내부 도구 산출물로 예외 처리해도 되는지 사용자에게 확인.
