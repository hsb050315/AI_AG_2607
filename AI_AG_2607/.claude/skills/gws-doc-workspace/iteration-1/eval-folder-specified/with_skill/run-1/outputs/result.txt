=== 참고: 실행 중 발견한 기술적 이슈 (Windows 환경) ===

gws_docs_builder.py는 shutil.which("gws")로 gws.cmd를 찾아 subprocess.run으로 실행하는데, Windows에서 .cmd 파일 실행은 내부적으로 cmd.exe를 거치므로 --json 인자 문자열 내부에 포함된 cmd.exe 특수문자가 인자 경계에 영향을 준다. 이번 실행에서 실제 조사 내용 텍스트에 포함되어 있던 두 문자에서 문제가 발생해 대체 문자로 치환했다:
1. "|" (파이프) → UnicodeDecodeError 유발 (batchUpdate 호출 자체가 깨진 JSON을 받음)
2. "&" (앰퍼샌드, 예: "캠핑&피크닉페어") → "EOF while parsing a string" 오류로 batchUpdate 실패 (JSON 문자열이 중간에 잘림)
두 경우 모두 gws_docs_builder.py 자체는 수정하지 않고(SKILL.md 지침 준수), 콘텐츠 텍스트에서 해당 문자를 "·"(가운뎃점)로 치환하는 방식으로 우회했다. 최종 문서는 전체 재검증을 거쳐 모든 섹션/표/글머리 목록이 정상적으로 저장된 것을 확인했다.
