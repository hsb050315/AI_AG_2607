=== 실행 결과 요약 (without_skill baseline) ===

요청: "여행 지도 폴더에 2026년 국내 캠핑장비 트렌드 조사해서 구글 문서로 정리해줘"

수행한 작업:
1. WebSearch로 "2026년 국내 캠핑장비 트렌드", "2026 캠핑 시장 규모 국내 전망",
   "2026 캠핑용품 인기 브랜드 신제품 에어텐트 차박" 등 3회 조사 수행.
2. Bash로 로컬 gws CLI(Google Workspace CLI, hsb050315@gmail.com OAuth 인증)가
   설치되어 있음을 확인하고 사용.
3. gws drive files list로 Google Drive에서 "여행 지도" 폴더를 검색해
   folder id(1lLAw5RN3aR8hFr6xcv6EHkLu9TwVwXq9)를 찾음.
4. gws docs documents create로 빈 Google Docs 문서 생성.
5. Python 스크립트로 제목/부제/H1/H2/본문/글머리 기호 목록 구조의 콘텐츠와
   각 문단의 인덱스를 계산해 batchUpdate 요청 JSON을 생성.
6. gws docs documents batchUpdate로 문서 본문 삽입 및 문단 스타일(TITLE, SUBTITLE,
   HEADING_1, HEADING_2, NORMAL_TEXT, 글머리 기호 목록) 적용.
7. gws drive files update(addParents/removeParents)로 문서를 "여행 지도" 폴더로 이동.

생성된 문서:
- 제목: 2026년 국내 캠핑장비 트렌드 조사
- 위치: Google Drive > 여행 지도 폴더
- 링크: https://docs.google.com/document/d/1uWrz0-0smIGbD3_AAGknxnI1QRSJGgvrdfRWgLbMgZE/edit?usp=drivesdk
- 문서 구성: 1. 시장 개요 / 2. 2026년 핵심 트렌드 키워드 / 3. 제품별 트렌드
  (3.1 에어 텐트, 3.2 캠핑 가구, 3.3 차박 용품) / 4. 시사점 / 5. 참고 자료(출처 링크)

참고: 이번 실행은 gws-doc 스킬을 사용하지 않고, 대화 맥락에 남아 있던 "gws CLI 설치됨"
레퍼런스 메모리와 일반적인 Google Docs API 지식(batchUpdate, 문단 인덱스 계산 등)만으로
직접 스크립트를 작성해 처리한 baseline(without_skill) 결과임.

구성:
1. 시장 개요 — 국내 캠핑 산업 규모(2024년 약 8조 원)와 글로벌 시장 성장 전망
2. 2026년 핵심 트렌드 키워드 — 편안함, 경량화, 지속가능성, 스마트 기술
3. 제품별 트렌드
   - 에어 텐트: 코베아·미니멀웍스·어반사이드·카즈미·몬테라 등 에어빔 구조 신제품 대거 출시
   - 캠핑 가구: 경량화 + 스마트 기능, 멀티펑션 제품 강세
   - 차박 용품: 전기 캠핑카·차박 특화 아이템 관심 증가
4. 시사점 — 초보 진입 장벽 하락, 고급화·미니멀 양극화, 경량화·멀티펑션 공통 키워드
