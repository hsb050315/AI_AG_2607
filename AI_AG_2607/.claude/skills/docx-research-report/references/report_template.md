# 보고서 작성 예시 (.txt 버전 실제 사례)

아래는 이 스킬로 작성한 실제 보고서(.txt 버전)의 예시다. 섹션 구성, 표 형태, 유의사항 작성 방식을 그대로 참고한다. 주제가 다르면 3번 섹션의 세부 형태(표/서술)는 바뀔 수 있지만, 큰 골격(개요→요약→상세→결론→유의사항)은 유지한다.

  2) 해외구매대행 업체 (해외 사이트 직접 주문/직구는 조사에서 제외)
- 비교 기준: 상품 가격 + 배송비를 합산한 최종 구매 금액이 낮은 순서
- 제외 대상: 품절 상품, 국내 배송이 불가능한 상품, 해외 사이트 직접 주문(직구) 상품

## 다른 주제 유형에도 같은 골격을 적용하는 법

- **정책/제도 조사** (예: "전기차 보조금 정책 조사해줘"): 2번 "국내 판매처 비교" 자리에 "지역별/차종별 지원금 비교" 표가 들어간다. 유의사항에는 "정책은 예고 없이 변경될 수 있음"을 명시한다.
- **시장 동향/현황 조사** (예: "국내 OTT 시장 점유율 조사해줘"): 표 대신 서술형 분석이 중심이 될 수 있다. 이 경우에도 수치(점유율, 규모 등)가 나오면 표로 정리한다.
- **일반 주제 설명** (예: "OO 기술에 대해 조사해서 정리해줘"): "비교" 섹션 대신 "핵심 개념/현황" 섹션으로 대체하되, 개요→요약→상세→결론→유의사항 골격은 유지한다.
