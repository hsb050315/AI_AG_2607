# 색상 이름 → hex 매핑 (main_color 지정용)

사용자가 색을 이름으로 요청하면 아래 표를 참고해 적당한 hex로 변환한다. 표에 없는 색이나 뉘앙스(예: "좀 더 밝은 파랑")는 임의로 적절히 판단해서 고른다 — 표는 참고용이지 완전한 목록이 아니다.

| 요청 | hex |
|---|---|
| 남색/네이비 (기본값) | 1F4E79 |
| 파란색/블루 | 2E86AB |
| 하늘색/스카이블루 | 5DADE2 |
| 초록색/그린 | 2E7D32 |
| 청록색/틸 | 148F77 |
| 보라색/퍼플 | 8E44AD |
| 남보라/인디고 | 5B2C6F |
| 빨간색/레드 | C0392B |
| 주황색/오렌지 | D35400 |
| 노란색/옐로우 | D4AC0D |
| 분홍색/핑크 | C2185B |
| 갈색/브라운 | 6E4A2E |
| 회색/그레이 | 5D6D7E |
| 검정/블랙 | 1C1C1C |
