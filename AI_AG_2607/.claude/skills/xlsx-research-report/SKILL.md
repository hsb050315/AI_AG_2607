# xlsx 조사표 생성

두 가지 입력 경로 중 하나로 시작해서 `.xlsx` 표로 마무리하는 스킬이다. 매번 표 조립 코드를 새로 짜지 말고, 번들된 `scripts/xlsx_generator.py`의 함수를 그대로 가져다 쓴다.

## 입력 경로 판단

- **주제 기반**: 사용자가 특정 주제·상품·정책 등을 언급하며 조사를 요청하면 → 웹 조사 경로.
- **파일 기반**: 사용자가 기존 `.xlsx`/`.csv` 파일을 언급하거나 첨부하면 → 파일 분석 경로. (표가 아닌 pdf/docx 같은 비정형 문서는 이 스킬의 대상이 아니다 — 필요하면 사용자에게 표 데이터 파일로 달라고 요청한다.)

## 전체 흐름

### A. 주제 기반 (웹 조사)

1. **범위 확정** — 주제, 조사 시점, 비교 기준이 요청에서 충분히 명확하면 바로 진행한다. 대상이 특정되지 않을 때만 짧게 되묻는다. 애매하지만 합리적으로 가정 가능하면, 가정한 내용을 비고/메모 셀에 남기고 진행한다.
2. **웹 조사** — WebSearch/WebFetch로 조사한다.
   - 최소 2곳 이상의 출처를 교차 확인한다.
   - 가격·재고·정책처럼 변하는 정보는 조사 시점(오늘 날짜)을 표 어딘가(제목 부제 또는 메모)에 반드시 남긴다.
   - 검색 결과가 부족하거나 상충되면 억지로 채우지 말고 해당 셀에 "확인 불가"로 표기한다.
3. **표 구조화** — 비교 항목을 열로, 대상을 행으로 정리한다. 항목이 많으면 우선순위/추천 순으로 정렬한다.

### B. 파일 기반 (기존 데이터 분석)

1. **파일 읽기** — 언급된 xlsx/csv 파일을 연다 (xlsx는 `openpyxl.load_workbook`, csv는 표준 `csv` 모듈로 충분하다).
2. **요청 파악** — 사용자가 원하는 가공이 무엇인지 확인한다 (재정렬, 필터링, 서식 통일, 요약 등). 요청이 모호하면 원본 구조를 최대한 보존하면서 서식(색상/표 스타일)만 통일하는 쪽으로 기본 처리한다.
3. **재구성** — 가공된 데이터를 `scripts/xlsx_generator.py`의 함수로 새 워크북에 옮겨 담는다. 원본 파일은 건드리지 않고 새 파일로 저장한다.

### 공통: 표 조립 및 저장

`scripts/xlsx_generator.py`에 있는 함수를 그대로 사용한다. 직접 openpyxl로 저수준 조립을 새로 하지 않는다.

```python
import sys
sys.path.insert(0, "<이 스킬 폴더>/scripts")
from xlsx_generator import (
    new_workbook, add_title, add_table, add_note, freeze_header, save,
)

wb, ws = new_workbook(main_color="1F4E79")  # 색상 지정 방법은 아래 참고
ws.title = "조사표"

add_title(ws, "OO 조사표", cell="A1", span_cols=4)

headers = ["항목", "가격", "옵션", "비고"]
rows = [
    ["A", "10,000원", "-", "-"],
]
last_row = add_table(ws, headers, rows, start_row=3, start_col=1)
freeze_header(ws, row=4)

add_note(ws, "조사일자: 2026년 8월 10일 / 정보는 변동될 수 있음", cell=f"A{last_row + 2}")

save(wb, "output/research/OO_조사표.xlsx")
```

- 조사 시점과 정보 변동 가능성은 표 하단에 `add_note`로 항상 남긴다 (docx 스킬의 "유의사항"에 해당).
- 비교 항목이 많아 시트가 넓어지면 `freeze_header`로 헤더를 고정해 가독성을 확보한다.
- 성격이 다른 데이터는 시트를 나누는 것도 고려한다 (`wb.create_sheet("시트명")`).

### 색상(main_color) 정하기

- 사용자가 특정 색을 요청하면 그 색을 hex로 변환해 사용한다. 한국어 색 이름 예시는 `references/color_reference.md`를 참고한다.
- 색 지정 요청이 없으면 기본값(짙은 남색, `1F4E79`)을 그대로 쓴다. 매번 색을 되물을 필요는 없다.

## 파일명 및 저장 위치

- 저장 폴더: 현재 작업 디렉토리 안에 `output/research/` 폴더가 이미 있으면 그 폴더에, 없으면 새로 만들어서 그 안에 저장한다.
- 파일명: `<주제(공백은 언더스코어로)>_조사표.xlsx`. 파일 기반 경로에서는 원본 파일명을 참고해 `<원본명>_정리.xlsx`처럼 구분되게 짓는다.
- 저장 후 파일의 절대 경로를 사용자에게 알려준다.

## 하지 말아야 할 것

- 조사 없이 이미 알고 있는 지식만으로 표를 채우지 않는다 — 주제 기반 경로의 핵심은 "지금 시점" 조사다.
- 파일 기반 경로에서 원본 파일을 직접 덮어쓰지 않는다 — 항상 새 파일로 저장한다.
- 조사 시점과 정보 변동 가능성을 표에서 누락하지 않는다.
- 표가 아닌 서술형 텍스트로 비교 데이터를 채우지 않는다 — 이 스킬의 출력은 표 중심이다.
